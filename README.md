# Secure-Vault

A Python tool for encrypting and protecting sensitive files. Designed to demonstrate practical cryptography and secure file handling.

## Features
- Encrypt files with a password
- Decrypt files back to normal
- Simple and lightweight
- Works offline - your files never leave your computer
- No database needed

## How It Works
1. Choose a file you want to protect
2. Enter a password
3. Secure-Vault encrypts the file
4. To open it again, enter the same password to decrypt it
